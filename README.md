# Win Junction Scout

A high-performance Windows NTFS directory junction analyzer, reparse loop detector, and broken symbolic link scanner.

## The Problem

On Windows, NTFS directory junctions (`mklink /J`) and directory symlinks are frequently generated by software installers, package managers (npm, pnpm, cargo), Visual Studio, Docker, and system components.

A recurring problem occurs when junctions reference their own parent or ancestor directories, creating **infinite recursive directory loops** (e.g. `C:\Users\<User>\AppData\Local\Application Data\Application Data\...`). These loops cause:
- Windows File Explorer to freeze during search operations.
- Backup software, antivirus scanners, and tree-crawlers to enter infinite loops, exhausting disk space and memory.
- Broken junctions pointing to non-existent drive letters or unmounted volumes.

## Features

- **Infinite Loop Detection**: Traces realpath ancestry to pinpoint recursive reparse cycles.
- **Broken Link Discovery**: Identifies junctions and symlinks pointing to moved or deleted targets.
- **Traversal Limits**: Configurable depth limits (`--max-depth`) to safely audit huge drive hierarchies.
- **CI / Automation Ready**: Machine-readable `--json` output and exit code flag (`--check`).
- **Standalone Binary**: Includes `build_exe.bat` to compile a single-file executable (`dist\win-junction-scout.exe`) without requiring Python.

## Installation & Usage

### 1. Run with Python

```bash
# Scan current directory
python junction_scout.py

# Scan a specific directory
python junction_scout.py C:\Users\RAM\Desktop

# Limit traversal depth
python junction_scout.py C:\ --max-depth 4

# Structured JSON output
python junction_scout.py C:\Project --json

# Summary only
python junction_scout.py C:\Project --summary

# Exit with code 1 if loops or broken links exist (for CI)
python junction_scout.py C:\Project --check
```

### 2. Standalone Windows Executable (.exe)

Compile with the included batch builder:

```cmd
build_exe.bat
```

Run the standalone executable:

```cmd
dist\win-junction-scout.exe C:\ --summary
```
